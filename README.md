# mytuftstudio - Interaktives Portfolio & Storefront

Willkommen in meinem Repository! Hier liegt der Quellcode für mein selbst programmiertes, unabhängiges Online-Schaufenster. Da meine bisherigen Plattform-Shops geschlossen wurden, habe ich meine Programmierkenntnisse genutzt, um mir eine eigene, sichere Storefront aufzubauen.

## 🚀 Das Projekt
Dieses Projekt verbindet meine Leidenschaft für kreatives Handwerk (Kunstteppiche/Tufting) mit moderner Webentwicklung. Es dient als interaktives Schaufenster für meine physischen Kunstwerke sowie für digitale Code-Assets (z. B. Godot/GDScript-Templates).

## 🛠️ Meine Tech-Skills in diesem Projekt
* **Frontend:** HTML5 & CSS3 für ein responsives Design im Cyber-Look.
* **Logik:** JavaScript (Vanilla JS) zur prozeduralen Generierung der Produktkarten aus einem Objekt-Array.
* **Architektur:** Serverloses (Serverless) Hosting über **GitHub Pages**.
* **Payment-Infrastruktur:** Sichere, externe Zahlungsabwicklung und globale Steuer-Handhabung durch die Integration von **Ko-fi-Direktlinks**.
